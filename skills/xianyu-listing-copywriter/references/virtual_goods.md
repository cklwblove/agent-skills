# 虚拟商品资料

闲鱼「虚拟商品 / 电子资料」类文案专项规则。生成前先判断用户卖的是否属本类。

## 子类目

| 子类 | 示例 | 默认风格 |
|------|------|---------|
| 学习笔记 | 考研笔记、考证整理、课堂手写扫描 | 真实走心 / 简洁直出 |
| 题库/真题 | 历年真题汇编、错题整理（须自有版权或合法授权） | 简洁直出 / 专业靠谱 |
| 模板素材 | PPT、简历、海报、Notion 模板 | 简洁直出 |
| 教程/指南 | 自制操作手册、入门指南、经验合集 | 真实走心 / 专业靠谱 |
| 电子书籍 | 正版二手电子书转让、个人扫描（版权风险高，慎写） | 专业靠谱 |
| 设计源文件 | 原创 PSD/AI/Figma 素材 | 专业靠谱 |
| 软件/账号 | 见下方合规红线，默认拒绝生成违规文案 | — |

## 专属信息字段

虚拟商品除通用字段外，须确认：

| 字段 | 说明 | 缺省处理 |
|------|------|---------|
| 资料名称 | 科目/考试/软件/主题 | 从用户描述提取 |
| 资料形式 | 电子版/网盘/压缩包/PDF/Word/视频 | 默认「电子版资料」 |
| 内容概要 | 页数、章节、更新年份、是否含答案 | 正文首段写明 |
| 来源说明 | 自制整理/备考自用/原创模板 | 走心款、专业款必写 |
| 交付方式 | 闲鱼发货/网盘自动发/拍下即发 | 默认「拍下后闲鱼内发货」 |
| 适配人群 | 考研党/公考/职场/设计师等 | 写入「适用人群」节 |
| 技术栈 | 语言/框架/工具版本，或科目模块、文件格式 | 写入「技术栈」节，不可省略 |
| 是否可更新 | 一次性/持续更新至某日期 | 无则写「当前版本」 |

## 商品详情四节（必填）

虚拟资料正文 = 以下四节 + 交易提示。**四节缺一不可**，顺序不可调换。

| 节 | 写什么 | 最低要求 |
|----|--------|---------|
| **1. 资料简介** | 资料定位、主题、版次、页数/文件数、格式 | 1–3 句，让买家 3 秒内看懂卖什么 |
| **2. 核心内容** | 章节、题库、模板数量、配套答案/源码等实质清单 | 至少 3 条分点，写「有什么」而非空泛形容词 |
| **3. 技术栈** | 技术/知识/工具覆盖范围 | 至少 1 条；技术类写语言框架版本，非技术类写科目模块或文件格式 |
| **4. 适用人群** | 目标买家、备考/学习阶段、前置基础 | 至少 1–2 句，写清「谁适合买」 |

### 技术栈填写指引

| 资料类型 | 技术栈写法示例 |
|---------|---------------|
| 编程教程/源码 | `Vue3 + TypeScript + Vite + Pinia` |
| 考研/考证笔记 | `马原 · 毛中特 · 史纲 · 思修（2026大纲）` |
| 题库/真题 | `选择题 800+ · 主观题 120+ · 含解析` |
| PPT/简历模板 | `PPT 2016+ / WPS 可编辑 · 16:9` |
| 设计素材 | `PSD + AI · 可商用需另议` |
| 综合教程 | `PDF + 配套思维导图 · 支持打印` |

## 标题写法

- 结构：`{考试/主题}{资料类型} {年份/版次} {价格信号}`
- 搜索词：考研、公考、教资、雅思、PPT模板、简历模板、学习笔记、电子版
- 避免：「最全」「包过」「押题必中」「内部渠道」

**示例标题**

- `考研政治笔记 电子版 2026版`
- `教资综合素质 真题整理 拍下即发`
- `简历模板合集 PPT可编辑 9.9`

## 正文结构（已并入四节）

四节之外的补充信息放在「交易提示」：

- **来源与质量**：写入「资料简介」末句或「核心内容」首条
- **交付说明**：交易提示中写拍下后多久发、什么渠道
- **售后边界**：交易提示中写电子资料不退换

## 交付话术（合规）

| 推荐 | 避免 |
|------|------|
| 拍下后闲鱼内发网盘链接 | 加微信发资料 |
| 付款后24小时内发货 | 支付宝直转再发 |
| 详情页有内容截图预览 | 私信索取完整版 |
| 有问题闲鱼站内沟通 | 扫码进群领取 |

## 合规红线（不生成文案）

以下类型用户若要求撰写，须拒绝并说明原因：

| 类型 | 原因 |
|------|------|
| 破解软件/激活码/盗版安装包 | 平台盗版违规 |
| 未授权影视/课程/电子书全集 | 版权侵权 |
| 论文代写/降重/查重包过 | 平台违禁 |
| 考试答案买卖/作弊器材 | 违禁 |
| 游戏外挂/辅助/私服 | 违禁 |
| 声称「内部渠道」「官方未公开」 | 虚假 + 版权风险 |

可卖的合规表述方向：

- 「个人备考期间整理的笔记」
- 「原创模板，可商用需另议」
- 「正版购买后个人转让（须用户确认合法）」

## 结尾交易提示（虚拟类默认）

```
📩 交付：拍下后闲鱼内发链接，一般24小时内
💰 价格：{一口价/可小刀}
⚠️ 售后：电子资料一经发货不退换，请先看清详情截图
```

## 与敏感词联动

虚拟资料易触发「版权词」「盗版违规词」「平台风控词」（如论文、教育类）。生成后必须用 `xianyu-sensitive-word-check` 复检；命中高危词一律改写。
