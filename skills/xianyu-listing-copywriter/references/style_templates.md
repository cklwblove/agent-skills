# 文案风格模板

四种风格的标题句式、正文结构与完整示例。生成时替换 `{}` 占位符，保持口语化。

## 1. 简洁直出（concise）

**标题句式**：`{品牌}{品类}{成色} 低价出` / `{品类}{规格} 功能完好`

**正文结构**：
1. 一句话说明来源与状态
2. 2–3 个功能/外观卖点
3. 发货与成交催促

**示例**

输入：iPhone 13 128G 黑色，9成新，无拆修，2200 出，包邮

```
标题：iPhone13 128G 黑色 9成新 2200

正文：
个人闲置 iPhone13，一直贴膜戴壳，功能全部正常。
无拆无修，电池健康还行，面容指纹都好用。
成色如图，侧边有小磕碰已拍出，不影响使用。
爽快包邮，当天发货～
```

## 2. 真实走心（heartfelt）

**标题句式**：`个人闲置{品类} 忍痛出` / `{品类} 自用{时长} 成色超新`

**正文结构**：
1. 入手渠道与使用故事（1–2 句）
2. 保养细节与个人感受
3. 转手原因 + 适合人群
4. 诚意议价话术

**示例**

输入：戴森 V10 吸尘器，用了一年，搬家急出，1500，可小刀

```
标题：戴森V10 自用一年 搬家忍痛出

正文：
这款 V10 是去年双十一自己买的，日常吸地毯和沙发缝。
每周都会清理尘杯，滤网也换过，吸力还是杠杠的。
搬家东西太多带不走，转让给有需要的朋友。
适合租房党或养宠家庭，诚心要可以小小刀，非诚勿扰～
```

## 3. 捡漏超值（bargain）

**标题句式**：`捡漏！{品牌}{品类} 半价出` / `{品类} 急出 比新品省一半`

**正文结构**：
1. 原价 vs 售价对比（有据可依）
2. 稀缺/急出理由
3. 正品或状态保证（不用极限词）
4. 紧迫感收尾

**示例**

输入：AirPods Pro 二代，官网入手，用了两次，700 出

```
标题：捡漏！AirPods Pro2 几乎全新

正文：
官网正品入手，小票还在，就试戴了两次。
原价一千多，现在 700 急出，比买新的省一大截。
降噪和通透都正常，充电盒无明显划痕。
就这一副，先到先得，拍下当天发～
```

## 4. 专业靠谱（professional）

**标题句式**：`正品{品类} 功能全好 放心入` / `{品牌}{型号} 无暗病 支持验货`

**正文结构**：
1. 正品来源与验货说明
2. 逐项功能/配件清单
3. 瑕疵透明披露
4. 包装发货与售后态度

**示例**

输入：MacBook Pro 2020 M1 16G 512G，95新，5800，顺丰包邮

```
标题：MacBook Pro M1 16G 功能全好

正文：
国行正品，序列号可查，支持同城面交验机。
16G+512G 配置，办公剪辑都够用，循环次数不高。
屏幕无亮点，键盘触控板正常，仅底壳一处轻微划痕。
实拍所见即所得，无暗病无维修。
顺丰包邮，包装严实，有问题提前说，不扯皮～
```

## 占位符速查

| 占位符 | 来源 |
|--------|------|
| `{品牌}` `{品类}` `{规格}` | 用户输入 |
| `{成色}` | 全新/99新/95新/9成新/成色如图 |
| `{原价}` `{售价}` | 用户输入，无则省略对比 |
| `{使用情况}` `{转手原因}` | 走心款、捡漏款 |
| `{瑕疵}` | 如实填写，专业款必写 |
| `{发货方式}` | 包邮/自提/顺丰到付 |

## 5. 虚拟商品资料（virtual）

虚拟类不按实物四风格硬套，在简洁/走心/专业中选最贴切的 1 种；交付与售后话术固定走电子版逻辑。细则见 [virtual_goods.md](virtual_goods.md)。

**标题句式**：`{考试/主题}{资料类型} {年份} {价格}` / `{模板类型} 电子版 拍下即发`

**正文结构**：
1. 资料内容与版次（页数、章节、是否含答案）
2. 适配人群与备考阶段
3. 来源说明（自制整理/原创模板）
4. 交付方式（闲鱼内发链接）
5. 电子资料不退换说明

**示例 A — 学习笔记（走心款）**

输入：考研政治笔记，自己整理，2026版，含马原毛中特，PDF 约200页，15 元

```
标题：考研政治笔记 2026版 电子版

正文：
去年备考自己整理的考研政治笔记，按最新大纲梳理。
马原、毛中特、史纲、思修都有，重点标红，约200页 PDF。
适合刚开始复习、需要框架梳理的同学，排版清晰可直接打印。
拍下后闲鱼内发网盘链接，一般当天能发。
电子资料发货后不退换，详情页有目录截图可先看清～
```

**示例 B — 模板素材（简洁款）**

输入：简历模板 20 套，PPT 可编辑，9.9 一口价

```
标题：简历模板20套 PPT可编辑 9.9

正文：
20 套求职简历 PPT 模板，自己设计整理，可编辑换字换色。
适合应届生、转行求职，拍下即发网盘链接。
详情页有预览图，看清再拍。
电子商品不退换～
```

**示例 C — 题库整理（专业款）**

输入：教资综合素质历年真题整理，含解析，2020-2025，12 元

```
标题：教资综合素质 真题整理 含解析

正文：
教资笔试综合素质科目，2020-2025 历年真题个人整理版。
题目按章节归类，附参考答案与简要解析，PDF 格式。
适合刷题冲刺阶段，拍下后闲鱼内发货。
内容为自己备考整理，仅供学习参考。
电子资料一经发货不退换，请先查看详情截图～
```
