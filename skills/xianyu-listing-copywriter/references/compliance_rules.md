# 合规规则

生成文案时的硬性约束。违反任一条须改写后再输出。

## 禁止出现

| 类别 | 示例 | 替代表达 |
|------|------|---------|
| 外部引流 | 加微信、vx、私聊、看主页 | 闲鱼站内沟通 |
| 私下交易 | 不走平台、线下转账、支付宝直转 | 平台下单 |
| 极限词 | 最便宜、第一、100%、全网最低 | 性价比高、比新品省不少 |
| 虚假承诺 | 假一赔万、绝对正品、稳赚 | 正品入手、小票/序列号可查 |
| 医疗功效 | 治疗、根治、消炎药效 | 删除或改成功能描述 |
| 高仿暗示 | 1:1、原单、尾单渠道、高仿 | 删除 |
| 联系方式 | 手机号、QQ号、邮箱、外链 | 删除 |

## 标题自检

- [ ] 15–20 字
- [ ] 无极限词、引流词、联系方式
- [ ] 价格数字与用户提供一致（未提供则不写具体价）
- [ ] 成色描述不夸张（「全新」需确为未使用）

## 正文自检

- [ ] 分段清晰，无大段堆砌
- [ ] 瑕疵与配件情况如实
- [ ] 无暗示绕开平台交易
- [ ] 无版权敏感品类违规描述（破解、盗版资料、代写论文等）

## 虚拟商品资料附加自检

识别为虚拟类时，额外核对 [virtual_goods.md](virtual_goods.md)：

- [ ] 交付写「闲鱼内发货/发链接」，无站外联系方式
- [ ] 未承诺包过、押题、内部渠道
- [ ] 未涉及破解/盗版/代写/外挂
- [ ] 已说明电子资料不退换
- [ ] 来源表述诚实（自制整理/原创模板），不冒充官方

## 常见安全替换

| 风险写法 | 安全写法 |
|---------|---------|
| 全网最低 | 价格好商量 / 比专柜省不少 |
| 100%正品 | 正品入手，支持验货 |
| 加微信看细节 | 细节已拍图，有问题站内聊 |
| 假一赔十 | 描述属实，不符可协商 |
| 治疗脱发 | 个人使用效果因人而异（美妆类慎写功效） |
| 加微信发网盘 | 拍下后闲鱼内发链接 |
| 包过押题内部渠道 | 个人整理仅供学习参考 |
| 最全资料合集 | 整理版 / 按章节归类 |

## 与敏感词 Skill 联动


```bash

```
